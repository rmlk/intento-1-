Proyecto de Certificación

Pasos para ejecutar la aplicación de forma local: 

Paso 1: Crear y activar un entorno virtual de Python.
Paso 2: Instalar las librerías necesarias con el comando: 

pip install -r requirements.txt

Usa el código con precaución.
Paso 3: Importar el archivo de la base de datos que está en flask_app/bd/schema.sql.
Paso 4: Abrir el archivo flask_app/config/mysqlconnection.py y cambiar la contraseña de la base de datos por la tuya local.
Paso 5: Iniciar el servidor ejecutando: 

python server.py

Usa el código con precaución.
